event → shared poster → balanced JE (DR = CR) + document + links: financial ⇄ operational
The lifecycle every process travels
1Spec→ 2Built→ 3Merged→ 4Proof→ 5Passed→ 6Complete
Spec = locked in blueprint · Built = code written · Merged = on main + migration applied on Neon · Proof = GUARD clicks it live & checks Neon · Passed = live-verified, any defect fixed & re-proven · Complete = certified on the ledger. A defect found at Proof loops back to fix, then re-proves.

Part B — Every other end-to-end process (same engine)

Each is its own vertical slice, each on the same 6-stage lifecycle. Certification runs in money order in Phase 2.

New Customer
Trigger: create customer (universal picker/creator)
Canonical entity-scoped write; A/R-ready; links ⇄ loads, invoices, factoring. Relationship health live (LV-001 fixed, proven on prod).
Spec: QBO Lists parity · picker canonical write + entity isolation proven live.
New Driver onboarding
Trigger: onboard driver
One txn: driver + driver-vendor + W-8BEN + escrow ledger + pay_basis + Driver Receivable.
Spec: MUST 3.13.1 · B1 1099, no US withholding · accounting skill §4.
Chart of Accounts
Trigger: CoA setup / edit
Additive only (never delete/rename); roles bound (unbilled_revenue, ar_control, revenue_default) per entity.
Spec: accounting skill §6 · 1,368 accounts · roles active TRANSP + USMCA.
Driver Settlement
Trigger: delivered loads in the period (weekly, per-driver overridable)
Header + pay lines + deductions + escrow = Net → Bill vs driver-vendor + Payment
Gross (rate × shortest miles) − deductions + reimbursements = net; 5% floor; debt shown in red.
Spec: settlement blueprint · states draft/presettlement/final/voided · unblocked by WIRE-02.
Driver Advance / Loan
Trigger: cash advance to driver
DR Driver Cash Advance (ASSET) / CR Cash
Recovered through settlement, capped by the net-pay floor; links ⇄ driver, bill_payment.
Spec: accounting skill §4 · driver_finance.advances running balance.
Deductions
Trigger: fine / damage / advance payback
Separate itemized ledger, running balance per obligation (not negative pay lines); WF-036 ack gate before settlement closes.
Spec: settlement blueprint §1 · fully auditable recovery trail.
Escrow
Trigger: escrow deposit / separation payout
DR Cash / CR Driver Escrow (LIABILITY) · forfeit → contra
Held-in-trust sub-ledger, control = Σ per-driver balances; returned 60–90d post-separation.
Spec: accounting skill §4 · escrow is a LIABILITY, never an asset.
Expense / Bill / AP
Trigger: vendor bill or expense
Bill: DR Expense/Asset / CR A/P (QBO-47) · Pay: DR A/P / CR Cash
Per-line load/unit/driver cost tags; vendor is a real FK; A/P aging by vendor.
Spec: standards parity §1 · createBill/payBill posting fixed (#2323/#2324).
Fuel
Trigger: fuel card txn (ComData / Relay)
Chain: fuel card → driver → unit → IFTA (miles/gallons by state) → settlement; fuel expense FK to the load.
Spec: QBO parity §6 · IFTA quarterly prep · test battery step 13.
Maintenance Work Order
Trigger: WO on a unit
Parts (→inventory→GL) + labor → Maint/Parts Expense + Maintenance Bill (A/P)
WO ⇄ unit ⇄ vendor ⇄ GL, both-way; parts ⇄ inventory.
Spec: test battery step 17 · parts catalog + PM · money-gate guard active.
Full Accident chain
Trigger: accident / safety incident
Depth: accident ⇄ driver ⇄ unit ⇄ trailer ⇄ load → claim ⇄ policy → at-fault: driver_liabilities carries full company-funded repair (WF-036 ack) → damage_recovery = contra-expense (never income).
Spec: test battery steps 19–24 · owner ruling 2026-07-23 · DIRE-ACCIDENT linkage proof.
Insurance
Trigger: claim filed / insurer pays
Deductible booked · recovery → CREDIT the SAME expense (never sales income)
Claim ⇄ accident ⇄ policy ⇄ unit ⇄ driver.
Spec: test battery step 22 · substance-over-form recovery treatment.
Legal Matter + Civil Fine
Trigger: lawsuit or civil/safety fine
Legal cost → legal-cost GL · fine → fine expense/liability
Legal stores documents/consents; Accounting posts (separation of duties). Fine ⇄ safety event.
Spec: test battery steps 23–24 · civil_fines_expense.
Factoring
Trigger: factor an invoice (Faro → RTS)
DR Cash + DR Fee/Reserve / CR Factoring Advance (LIABILITY)
A/R stays on IH35 books as pledged collateral — no derecognition; secured borrowing, not a sale.
Spec: accounting skill §3 · ASC 860 recourse · Advance + Reserve + Recoursed.
Banking / Reconciliation
Trigger: bank feed + twice daily
AM count/sum 06:00 CT, PM categorization diff 19:00 CT; every divergence flagged (no $ threshold); read-only.
Spec: accounting skill §8 RECON-01 · TMS_QBO_RECON_ENABLED default OFF · 18/19.
