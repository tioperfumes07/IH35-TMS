## HAVE / MISSING / DRIFT / WILL FAIL

**HAVE:** Profiles persistence; banking import with virtual exclusion; print/PDF; mark filed; amend; exhibits builder; dual company keys (trucking/transportation).

**MISSING:** Arch KPI strip; URL-deep-linkable tabs; exhibits as in-module sub-nav (live is separate page — keep route, don’t delete); counsel-confirmed DIP account list filter.

**DRIFT:** Arch 9 tabs (Form + Exhibits A–F + Merge + History) vs live 5 + `/425c/exhibits`. Exhibit letter meanings in UI meta differ from arch table (arch A=Part1 explanations; live A=cash receipts). QB Import is paste-parse, not QBO sync (parallel-books: no TMS→QBO write-back — OK, but label honestly).

**WILL FAIL**
1. **Bookmark Form vs Profiles tab** — always lands Profiles (`useState("profile")`).
2. **Wrong petition date on new reports** — hardcoded `2025-02-03` (`Form425CHome.tsx:209`).
3. **Treating arch 9-tab layout as shipped** — operators trained on design PNG will not find Exhibit tabs in sub-nav.
4. **Filing with Factoring/Escrow still in profile bank list for QB paste** — banking import excludes virtual; QB paste path can still apply totals if operator pastes virtual-bank deposits into Line 20 (`QBImportTab` Apply) — human error risk.

## Professional recommendation
Court/CPA bar: (1) Fix petition date to profile/case field (no hardcode). (2) Sync arch MODULE 14 to live structure **or** add URL tabs + in-page exhibit nav without removing `/425c/exhibits`. (3) Keep virtual-bank exclusion; add UI banner “Factoring & Escrow excluded from lines 19–23 per UST.” (4) Owner+counsel gate for curated DIP accounts before claiming legal authority. Never delete 425C module or exhibits route.
