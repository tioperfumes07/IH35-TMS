## P011/P012/P014 — proportional table header floor (separate follow-up)

The prior floor reserves 48px per text column regardless of header width or its percentage share. A 180px minimum column receives only 108.25px at that floor; an explicit caller floor of 100px reduces it to 50.12px. Two regression cases reproduce both failures.

Repair computes the minimum table width required by each measured header's actual percentage share, preserving figure-column pixels and user resize proportions.
