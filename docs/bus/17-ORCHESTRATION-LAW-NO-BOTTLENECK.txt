################ RULE 1 — STANDING LANES. A SEAT NEVER WAITS TO BE TOLD. ################
Each seat OWNS a permanent lane and a QUEUE FILE with ordered work items.
When a seat finishes an item, it POPS THE NEXT ITEM FROM ITS OWN QUEUE.
It does not ask. It does not wait. It does not ACK. It works.

  docs/bus/QUEUE-<SEAT>.md   -- ordered list, top item is current work
  Max 40 lines. Cursor refills it when it drops below 3 items.
  Popping an item = deleting that line. The queue only shrinks as work is done.

A seat is IDLE only if its queue is EMPTY. That is the only legitimate idle,
and it is Cursor's failure to refill, not the seat's failure to work.

################ RULE 2 — NO SEAT EVER WAITS ON ANOTHER SEAT ################
Blocked on your current item? Do not report and stop. Do not wait for a gate.

inside ONE seat's queue — never across seats.
