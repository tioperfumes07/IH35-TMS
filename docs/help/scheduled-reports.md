# Scheduled reports

Scheduled reports email or queue recurring report packs so owners and managers do not re-run the same filters weekly.

## Overview
- From Reports (or the scheduled-reports surface), define which report, which company, which cadence, and which recipients.
- Schedules are company-scoped; a TRANSP schedule does not send TRK data.
- Failed deliveries should surface in the schedule history / email queue for ops follow-up.

## Key tasks
- Create a schedule for a proven report (verify filters manually once first).
- Set cadence (daily/weekly/monthly) and recipient list.
- Pause or edit a schedule when staffing or SOP changes.
- Investigate bounced email via the email queue / notifications surfaces.

## Tips & gotchas
- Always dry-run filters before enabling a schedule for executives.
- Attachments can be large — prefer CSV for data packs when PDF is unnecessary.
- Do not put secrets in report titles; schedules may appear in shared inboxes.
