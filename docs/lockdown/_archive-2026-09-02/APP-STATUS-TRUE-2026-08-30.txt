3. THE BUCKETS — what the four boxes in every cell mean
===============================================================================
Every matrix cell draws four boxes, left to right:

     BOX 1  REQUIRED   this cell is declared in <module>.required.json
     BOX 2  AUDITED    someone checked it   (shows a dot when audited but not built)
     BOX 3  BUILT      a wire-sprint guard ships for it
     BOX 4  LIVE       proven on the running deploy

  source: apps/frontend/src/pages/program/moduleMatrixBoxes.tsx:110-113

  So the pattern you are seeing everywhere -  V O X X  - reads exactly:
     required yes / audited yes / BUILT NO / LIVE NO.

  The rollup is strict on purpose: a module box only goes green at 100%.
  Accounting at 98% draws a red BUILT box. That is the board being honest,
  not the board being broken.
